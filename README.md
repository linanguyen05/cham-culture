## Setup

1. Ensure you have a modern browser (Chrome, Edge, Firefox).
2. If the project uses a dev server (e.g. Vite, webpack, or similar), install dependencies and run the dev server:

```powershell
# from folder \vhc\frontend
# npm install
# npm run dev
```

If no JS tooling is used, you can open `index.html` directly in the browser.

## Run

- For static sites: open `index.html` in your browser.
- For dev servers: use the project's npm/yarn scripts (e.g. `npm run dev`).
